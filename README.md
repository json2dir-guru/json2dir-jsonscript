# json2dir-jsonscript

[json2dir](https://github.com/kitsunoff/awesome-json2dir) written as a [JSONScript](https://github.com/JSONScript/jsonscript) program (`json2dir.jsonscript.json`), run by the jsonscript-js interpreter; `run.js` only parses stdin and exposes single fs operations plus a few pure helpers.

    npm ci && node run.js < document.json
